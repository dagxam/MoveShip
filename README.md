# 🚢 MoveShip

> **Управляемые корабли для Paper** — построй корабль из обычных блоков, установи кафедру управления и отправляйся в плавание.

## ✨ Возможности

**MoveShip** превращает связанную конструкцию из блоков в управляемый корабль. Основная визуальная часть корабля переносится через `BlockDisplay`, поэтому корпус двигается как единая конструкция, а повороты выполняются с интерполяцией.

### 🎮 Управление

| Действие | Клавиши / кнопка |
|---|---|
| Движение вперёд | `W` |
| Движение назад | `S` |
| Поворот влево | `A` |
| Поворот вправо | `D` |
| Остановка | Кнопка **«Остановить»** в меню |

Скорость и поворот изменяются плавно, без резкого переключения между состояниями.

## 🧭 Как начать

### 1. Создай кафедру управления

Специальная **«Кафедра управления»** — это уникальный предмет MoveShip на основе кафедры Minecraft.

Рецепт:

```text
П П П
Б Б Б
```

Точная раскладка рецепта:

```text
P P P
L L L

P = любой блок из Tag.PLANKS
L = любой блок из Tag.LOGS
```

После установки предмет превращается в настоящее **ядро корабля**.

### 2. Построй корабль

Поставь рядом с кафедрой связанные блоки корпуса. Сканер работает по объёмной связности и может захватывать блоки по всем 26 соседним направлениям.

В корабль входят, помимо корпуса:

- деревянные конструкции: доски, брёвна, ступени, плиты, двери, люки, заборы и т. д.;
- стекло, стеклянные панели, шерсть, ковры и другие декоративные элементы;
- светящиеся блоки, фонари и источники света;
- рельсы и элементы железнодорожной инфраструктуры;
- редстоун-механизмы;
- функциональные блоки;
- контейнеры и блоки с инвентарями.

Размер одного корабля ограничен **8192 блоками**. Это защищает сервер от случайного сканирования слишком большой области.

### 3. Открой меню

Нажми **ПКМ** по установленной кафедре управления.

Откроется меню:

| Кнопка | Назначение |
|---|---|
| 🧭 **Сканировать** | Находит и фиксирует связанную конструкцию |
| ✅ **Активировать** | Переводит корабль в режим движения |
| 🛑 **Остановить** | Возвращает физические блоки на новое положение |
| 🚪 **Выход** | Закрывает меню |

После активации управление выводится в сообщении:

```text
W/S — движение
A/D — поворот
```

## 📦 Сохранение содержимого

MoveShip не ограничивается сохранением внешнего вида блоков.

При активации корабля сохраняются:

- `BlockData` — ориентация и свойства блока;
- `BlockState` — состояние функциональных блоков;
- содержимое контейнеров;
- предметные слоты специальных блоков;
- состояния редстоун- и функциональных блоков, если они представлены соответствующим состоянием блока.

Поддерживается сохранение содержимого **сундуков, двойных сундуков, бочек, печей, воронок, раздатчиков, выбрасывателей, крафтеров, варочных стоек, шалкеров** и других блоков с инвентарём, которые доступны через Paper API.

### 🧰 Особый случай: двойные сундуки

Двойной сундук обрабатывается по половинам.

Для каждой половины используется отдельный 27-слотовый снимок, поэтому левое и правое отделения не должны перезаписывать друг друга при перемещении корабля.

Это особенно важно для кораблей с большими грузовыми трюмами.

## 💡 Свет

Светящиеся блоки сохраняются в составе корабля.

Во время движения MoveShip использует временные `LIGHT`-блоки для поддержания реального освещения мира в текущем положении корабля. Внешний вид при этом остаётся на `BlockDisplay`.

При остановке временные источники света удаляются, а физические светящиеся блоки восстанавливаются.

## 🌊 Вода

Корабль можно активировать прямо в воде.

MoveShip определяет исходный уровень воды и после удаления физического корпуса восстанавливает воду только в подводной части старого положения. Это предотвращает появление больших вертикальных водяных стен.

## 🧱 Коллизии

Перед каждым изменением положения проверяется целевая область корабля.

Воздух и вода не считаются препятствием, а реальные твёрдые блоки в целевой области блокируют перемещение.

Благодаря этому визуальная интерполяция не должна проталкивать корабль через обычные препятствия.

## 🎞️ Плавность

Визуальный корпус построен вокруг пассажирской цепочки:

```text
ArmorStand displayCarrier
        │
        ▼
    BlockDisplay
        │
        ├── BlockDisplay
        ├── BlockDisplay
        ├── BlockDisplay
        └── ...
```

Отдельные `BlockDisplay` не телепортируются каждый тик. Движение корпуса передаётся через единый carrier, а поворот меняет transformation matrix с интерполяцией.

При наличии **ProtocolLib** MoveShip дополнительно отправляет синхронизацию позиции для carrier-а. ProtocolLib является необязательной зависимостью.

## ⚙️ Технические требования

| Компонент | Версия |
|---|---|
| Minecraft / Paper | **Paper 26.x** |
| Paper API | `26.3.build.32-alpha` |
| Java | **26** |
| Система сборки | Maven |
| ProtocolLib | Необязательно |

> В проекте используется `api-version: 26.2`, а сборка выполняется против Paper API `26.3.build.32-alpha`.

## 🛡️ Ограничения

MoveShip специально защищает сервер от опасного массового сканирования: максимум **8192 блока** на корабль.

Во время движения физические блоки корабля временно заменены визуальным представлением. Поэтому интерактивные GUI функциональных блоков не работают как обычные мировые блоки непосредственно в полёте; их состояния и содержимое сохраняются для восстановления после остановки.

## 🔨 Сборка

Проект собирается на **Java 26**:

```bash
mvn -B clean package
```

Готовый файл:

```text
target/MoveShip-1.0.0.jar
```

Также в репозитории настроен GitHub Actions для автоматической сборки.
